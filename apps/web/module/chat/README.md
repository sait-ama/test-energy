# Чат-модуль

## Обзор

Данный модуль предоставляет функциональность чата для приложения. Модуль находится в процессе рефакторинга, в ходе которого была удалена устаревшая система событий, которая будет заменена на новую реализацию.

## Точки входа

Модуль имеет несколько точек входа для разных типов чата:

- **ChatApp.tsx** - Основное приложение чата для личных сообщений
- **GuildChatApp.tsx** - Приложение чата для гильдий
- **ChatApp.async.tsx** и **GuildChatApp.async.tsx** - Асинхронные варианты для оптимизации загрузки

Каждое приложение предоставляет обертку с необходимым контекстом и Suspense для асинхронной загрузки.

## Основная модель данных

### Типы каналов

```typescript
export enum ChannelType {
  PRIVATE = 'private', // Личный чат
  GROUP = 'group', // Групповой чат
  GUILD = 'guild', // Чат гильдии
```

### Типы событий сообщений

Система использует следующие типы сообщений, приходящие с бэкенда по REST API:

```typescript
export enum MessageEventType {
  MEMBER_JOIN = 'MEMBER_JOIN', // Участник присоединился к комнате
  MEMBER_LEAVE = 'MEMBER_LEAVE', // Участник покинул комнату
  ROOM_NAME_CHANGE = 'ROOM_NAME_CHANGE', // Изменение названия комнаты
  ROOM_COVER_CHANGE = 'ROOM_COVER_CHANGE', // Изменение обложки комнаты
  MESSAGE = 'MESSAGE_NEW', // Новое сообщение
}
```

### WebSocket структура сообщений

Для работы с WebSocket используется другая структура сообщений:

```typescript
// Типы событий WebSocket
export enum WebSocketEventType {
  ROOM_EVENT = 'room_event',
  NOTIFICATION = 'notification',
  CONNECTION_STATE = 'connection_state',
}

// Тип события определяется полем discriminator
export enum RoomEventDiscriminator {
  MEMBER_JOIN = 'member_join',
  MEMBER_LEAVE = 'member_leave',
  MEMBER_ONLINE = 'member_online',
  MEMBER_OFFLINE = 'member_offline',
  ROOM_NAME_CHANGE = 'room_name_change',
  ROOM_COVER_CHANGE = 'room_cover_change',
  MESSAGE = 'message_new',
  MESSAGE_UPDATE = 'message_update',
  MESSAGE_DELETE = 'message_delete',
}
```

Пример WebSocket сообщения:

```json
{
  "type": "room_event",
  "event": {
    "room_id": 16,
    "data": {
      "discriminator": "message_new",
      "uuid": "89656d14-8a04-47ca-a70d-43c2a620d4b9",
      "local_uuid": "dacc3645-684a-4501-a82d-6f143ad476ae",
      "user_id": 3043591,
      "text": "Test message",
      "created_at": "2025-04-24T11:55:59.489818"
    },
    "message": null
  }
}
```

### структура сообщений

Сообщения имеют универсальную структуру с базовыми полями и специфичными данными в зависимости от типа:

```typescript
// Базовая структура сообщения
export type MessageMessageData = {
  uuid: string; // Уникальный идентификатор сообщения
  local_uuid: string; // Локальный UUID для временных сообщений
  user_id: number; // ID отправителя
  text: string; // Текст сообщения
  created_at: string; // Время создания
  attachments?: AttachmentSchema[]; // Вложения
  mentioned_users?: MessageUserSchema[]; // Упомянутые пользователи
};

// Структура вложения
export type AttachmentSchema = {
  media_type: 'image'; // Тип медиа
  extension: string; // Расширение файла
  width: number; // Ширина
  height: number; // Высота
  url: string; // URL файла
  is_original: boolean; // Флаг оригинального файла
};

// Структура пользователя в сообщении
export type MessageUserSchema = {
  id: number; // ID пользователя
  username: string; // Имя пользователя
  is_staff: boolean; // Флаг сотрудника
  avatar: any; // Аватар
  frame: any; // Рамка
  role: RoleChatUser; // Роль в чате
};

// Типы событий чата
export type MessageSchema =
  | MessageMessageEvent // Сообщение
  | MemberJoinMessageEvent // Присоединение участника
  | MemberLeaveMessageEvent // Выход участника
  | RoomNameChangeMessageEvent // Изменение названия комнаты
  | RoomCoverChangeMessageEvent // Изменение обложки комнаты
  | TypingStartMessageEvent // Начало набора
  | TypingStopMessageEvent // Окончание набора
  | MessageUpdateMessageEvent // Обновление сообщения
  | MessageDeleteMessageEvent; // Удаление сообщения
```

## Компоненты в директории common

Директория `components/common` содержит переиспользуемые компоненты для построения чата:

### Основные компоненты

- **chat/** - Основной компонент чата, содержащий логику и структуру

  - Включает контейнеры, провайдеры контекста и хуки управления состоянием
  - Обеспечивает подключение к WebSocket и обработку событий чата
  - Координирует работу всех остальных компонентов

- **channel/** - Компонент управления каналом, отображение и состояние канала

## Работа с WebSocket

Для получения обновлений в реальном времени используется WebSocket соединение. Модуль предоставляет утилиты для конвертации WebSocket событий в REST формат в файле `utils/websocket-converters.ts`:

```typescript
// Пример использования конвертера WebSocket событий
import { convertWStoRESTFormat, handleWebSocketEvent } from '../utils';

// Создаем WebSocket соединение
const ws = new WebSocket('wss://api.example.com/ws/chat');

// Обрабатываем входящие сообщения
ws.onmessage = (event) => {
  const wsEvent = JSON.parse(event.data) as WebSocketEvent;

  // Используем готовый обработчик с колбэками
  handleWebSocketEvent(wsEvent, {
    onMessage: (message) => {
      // Обновляем состояние UI с новым сообщением
      updateChannelState(message);
    },
    onConnectionStateChange: (state) => {
      console.log(`Connection state: ${state}`);
    },
    onNotification: (data) => {
      console.log('Notification received:', data);
    },
  });
};
```

## Отображение разных типов сообщений

Каждый тип сообщения требует специфического отображения:

```tsx
// Пример компонента для отображения разных типов сообщений
const MessageItem = ({ message }) => {
  switch (message.type) {
    case MessageEventType.MESSAGE:
      return <TextMessage data={message.data} />;

    case MessageEventType.MEMBER_JOIN:
      return <SystemMessage text={`${message.data.name} присоединился к чату`} />;

    case MessageEventType.MEMBER_LEAVE:
      return <SystemMessage text={`${message.data.name} покинул чат`} />;

    case MessageEventType.ROOM_NAME_CHANGE:
      return (
        <SystemMessage
          text={`${message.data.changed_by.name} изменил название комнаты на "${message.data.new_name}"`}
        />
      );

    case MessageEventType.ROOM_COVER_CHANGE:
      return <SystemMessage text={`${message.data.changed_by.name} изменил обложку комнаты`} />;

    default:
      return null;
  }
};
```
